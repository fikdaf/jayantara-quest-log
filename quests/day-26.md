## 🎯 Materi & Output Skill

Menyusun CV/Rirekisho (履歴書) ala Jepang — dokumen wajib untuk melamar kerja.

## 📄 Apa itu Rirekisho?

Rirekisho adalah format CV standar Jepang, biasanya ditulis tangan atau diketik dengan format baku, jauh lebih terstruktur dan formal dibanding CV bebas.

## 📋 Bagian-Bagian Rirekisho

| Bagian (Jepang) | Baca | Isi |
|---|---|---|
| 日付 | hizuke | Tanggal penulisan |
| 氏名 | shimei | Nama lengkap |
| 生年月日 | seinengappi | Tanggal lahir |
| 現住所 | genjuusho | Alamat tempat tinggal saat ini |
| 学歴 | gakureki | Riwayat pendidikan |
| 職歴 | shokureki | Riwayat pekerjaan |
| 資格 | shikaku | Sertifikat/kualifikasi (contoh: JLPT N5) |
| 志望動機 | shibou douki | Motivasi melamar |
| 本人希望記入欄 | honnin kibou kinyuu ran | Kolom permintaan pribadi (gaji, lokasi kerja, dll) |

## 🔤 Kosakata Pendukung

| Jepang | Baca | Arti |
|---|---|---|
| そつぎょう | sotsugyou | lulus (sekolah) |
| にゅうしゃ | nyuusha | masuk kerja di perusahaan |
| たいしょく | taishoku | keluar/berhenti kerja |
| しかく | shikaku | kualifikasi/sertifikat |
| どうき | douki | motivasi |

## 🗣️ Contoh Kalimat Motivasi (Shibou Douki)

> 私は日本語と技術を学び、日本で働きたいと思い、応募しました。
> (Watashi wa nihongo to gijutsu wo manabi, Nihon de hatarakitai to omoi, oubo shimashita.)
> = "Saya belajar bahasa Jepang dan teknik, dan karena ingin bekerja di Jepang, saya melamar."

## 📝 Checklist Belajar Hari Ini

- [ ] Hafalkan istilah-istilah bagian Rirekisho
- [ ] Susun draf Rirekisho versi sederhana untuk dirimu sendiri (nama, pendidikan, motivasi)
- [ ] Tulis 1 paragraf motivasi (shibou douki) tentang kenapa ingin kerja ke Jepang
- [ ] Cari contoh format Rirekisho resmi secara online untuk referensi visual
- [ ] Latihan tulis tanggal format Jepang (Reiwa/Heisei atau format tahun Masehi)
