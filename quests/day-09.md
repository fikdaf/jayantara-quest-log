# Day 09: Aktivitas Harian (Verba ~masu)

[← Kembali ke README](../README.md)

## 🎯 Materi & Output Skill

Pola kalimat kata kerja harian bentuk sopan (~masu).

## 📖 Pola Dasar Kalimat Verba

**[Waktu] ni [objek] wo [kata kerja]-masu.**

Bentuk ~masu adalah bentuk kata kerja sopan yang dipakai di percakapan formal dan tempat kerja.

## 🔤 Kata Kerja Harian Umum

| Jepang | Baca | Arti |
|---|---|---|
| おきます | okimasu | bangun tidur |
| ねます | nemasu | tidur |
| たべます | tabemasu | makan |
| のみます | nomimasu | minum |
| いきます | ikimasu | pergi |
| きます | kimasu | datang |
| かえります | kaerimasu | pulang |
| はたらきます | hatarakimasu | bekerja |
| べんきょうします | benkyou shimasu | belajar |
| やすみます | yasumimasu | istirahat |
| みます | mimasu | melihat/menonton |
| ききます | kikimasu | mendengar |
| かいます | kaimasu | membeli |
| つくります | tsukurimasu | membuat |

## 🗣️ Contoh Kalimat

- 毎朝6時に起きます。(Maiasa rokuji ni okimasu.) = "Setiap pagi saya bangun jam 6."
- 7時に朝ごはんを食べます。(Shichiji ni asagohan wo tabemasu.) = "Jam 7 saya makan sarapan."
- 8時に会社に行きます。(Hachiji ni kaisha ni ikimasu.) = "Jam 8 saya pergi ke perusahaan."
- 5時に家に帰ります。(Goji ni ie ni kaerimasu.) = "Jam 5 saya pulang ke rumah."

## ➖ Bentuk Negatif dan Lampau

| Bentuk | Akhiran | Contoh |
|---|---|---|
| Positif sekarang/akan | ~masu | tabemasu (makan) |
| Negatif sekarang/akan | ~masen | tabemasen (tidak makan) |
| Positif lampau | ~mashita | tabemashita (sudah makan) |
| Negatif lampau | ~masen deshita | tabemasen deshita (tidak makan/dulu) |
