# Day 21: Instruksi Kerja & Keselamatan (1) — Istilah Industri

[← Kembali ke README](../README.md)

## 🎯 Materi & Output Skill

Istilah lapangan kerja sektor industri/pabrik.

## 🏭 Kosakata Umum Sektor Industri

| Jepang | Baca | Arti |
|---|---|---|
| こうじょう | koujou | pabrik |
| せいさん | seisan | produksi |
| きかい | kikai | mesin |
| ぶひん | buhin | komponen/suku cadang |
| けんさ | kensa | pemeriksaan/inspeksi |
| ふりょうひん | furyouhin | barang cacat |
| ラインさぎょう | rain sagyou | kerja jalur produksi (line work) |
| こうてい | koutei | proses/tahapan kerja |
| ざいこ | zaiko | stok/persediaan |
| しゅっか | shukka | pengiriman barang |

## 🗣️ Instruksi Kerja Umum

| Jepang | Baca | Arti |
|---|---|---|
| これをやってください | kore wo yatte kudasai | tolong kerjakan ini |
| きをつけてください | ki wo tsukete kudasai | tolong hati-hati |
| はやくしてください | hayaku shite kudasai | tolong lebih cepat |
| もういちどおねがいします | mou ichido onegaishimasu | tolong sekali lagi |
| わかりました | wakarimashita | saya mengerti/paham |
| わかりません | wakarimasen | saya tidak mengerti |

## 🗣️ Contoh Dialog di Lantai Produksi

> **Atasan:** この部品を検査してください。(Kono buhin wo kensa shite kudasai.) — "Tolong periksa komponen ini."
> **Pekerja:** はい、わかりました。(Hai, wakarimashita.) — "Baik, saya mengerti."
> **Atasan:** 不良品があったら、教えてください。(Furyouhin ga attara, oshiete kudasai.) — "Kalau ada barang cacat, tolong beri tahu saya."
