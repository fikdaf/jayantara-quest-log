# Day 24: Instruksi Kerja & Keselamatan (4) — Istilah Program Magang

[← Kembali ke README](../README.md)

## 🎯 Materi & Output Skill

Istilah seputar program magang (Ginou Jisshuu) di Jepang.

## 📋 Kosakata Program Magang

| Jepang | Baca | Arti |
|---|---|---|
| ぎのうじっしゅう | ginou jisshuu | pemagangan keterampilan |
| じっしゅうせい | jisshuusei | peserta magang |
| かんりだんたい | kanri dantai | organisasi pengawas |
| じつぎしけん | jitsugi shiken | ujian praktik |
| がくしゅう | gakushuu | pembelajaran |
| けいやく | keiyaku | kontrak |
| きゅうよ | kyuuyo | gaji |
| しゃかいほけん | shakai hoken | asuransi sosial |
| りょう | ryou | asrama/tempat tinggal |
| きこく | kikoku | pulang ke negara asal |

## 📄 Kosakata Administrasi & Dokumen

| Jepang | Baca | Arti |
|---|---|---|
| ざいりゅうカード | zairyuu kaado | kartu izin tinggal |
| パスポート | pasupooto | paspor |
| びざ | biza | visa |
| けんこうしんだんしょ | kenkou shindansho | surat keterangan sehat |
| りれきしょ | rirekisho | daftar riwayat hidup |

## 🗣️ Ungkapan Penting saat Magang

| Jepang | Baca | Arti |
|---|---|---|
| しつもんがあります | shitsumon ga arimasu | saya ada pertanyaan |
| もういちどせつめいしてください | mou ichido setsumei shite kudasai | tolong jelaskan sekali lagi |
| きろくをつけます | kiroku wo tsukemasu | saya akan mencatat |
| がんばります | ganbarimasu | saya akan berusaha keras |

## 🗣️ Contoh Kalimat

> 実習生として、日本で技術を学びます。
> (Jisshuusei toshite, Nihon de gijutsu wo manabimasu.)
> = "Sebagai peserta magang, saya belajar teknik di Jepang."
