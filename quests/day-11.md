## 🎯 Materi & Output Skill

Kosakata i-keiyoushi (kata sifat -i) dasar.

## 📖 Apa itu I-Keiyoushi?

Kata sifat Jepang yang selalu berakhiran huruf い (i) di bentuk kamus. Bisa langsung dipakai sebelum kata benda tanpa partikel tambahan.

## 🔤 Kata Sifat -i Umum

| Jepang | Baca | Arti |
|---|---|---|
| おおきい | ookii | besar |
| ちいさい | chiisai | kecil |
| あたらしい | atarashii | baru |
| ふるい | furui | lama/tua (benda) |
| たかい | takai | tinggi/mahal |
| やすい | yasui | murah |
| いい / よい | ii / yoi | bagus |
| わるい | warui | jelek/buruk |
| あつい | atsui | panas |
| さむい | samui | dingin (udara) |
| おいしい | oishii | enak |
| むずかしい | muzukashii | sulit |
| やさしい | yasashii | mudah / baik hati |
| いそがしい | isogashii | sibuk |

## 📖 Pola Kalimat

**[Benda] wa [sifat-i] desu.**
Contoh: この部屋は大きいです。(Kono heya wa ookii desu.) = "Kamar ini besar."

**[Sifat-i] + [kata benda]** (langsung tanpa partikel)
Contoh: 大きい部屋 (ookii heya) = "kamar yang besar"

## ➖ Bentuk Negatif I-Keiyoushi

Ganti akhiran い → くない
- おおきい → おおきくない (ookikunai) = "tidak besar"
- たかい → たかくない (takakunai) = "tidak mahal"

⚠️ Perhatian: いい (bagus) tidak beraturan → bentuk negatifnya よくない (yokunai), bukan いくない.
