## 📁 Struktur Repositori

```
jayantara-quest-log/
├── README.md              ← File ini (overview & quest map)
├── LICENSE.md             ← Lisensi (All Rights Reserved)
└── quests/
    ├── day-01.md
```

Setiap file di folder `quests/` berisi materi, target belajar, dan kolom checklist untuk hari itu. Centang progress-mu langsung di file markdown-nya (`- [ ]` → `- [x]`) atau di GitHub Projects/Issues kalau mau tracking lebih visual.

## 🚀 Cara Pakai Repo Ini

1. **Fork / clone** repo ini ke akun GitHub kamu sendiri
2. Buka file `quests/day-01.md` dan mulai belajar
3. Setelah selesai satu hari, centang checklist di file harian itu, lalu update baris "Status" di tabel README ini jadi `[x]`
4. Commit progressmu tiap hari — bisa jadi bukti konsistensi belajar sekaligus histori GitHub kamu!
